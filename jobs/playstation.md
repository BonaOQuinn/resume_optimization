## Role Summary

Join Sony Interactive Entertainment and gain hands-on experience supporting the ongoing development of PlayStation’s Global Financial Reporting Systems. You'll work with the enterprise architecture team to build and improve scalable financial systems, with a focus on event-driven architectures, real-time data processing, and simple, intuitive frontends.

As an intern, you'll collaborate with engineers to develop technical solutions, improve existing applications, and explore how software engineering supports financial operations. This opportunity offers practical experience with backend development, data management, testing, and cloud technologies while contributing to projects that improve efficiency across the business.
