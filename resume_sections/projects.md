### Linux / Unix Server development
- Built and administered a multi-VM infrastructure environment across OpenBSD, FreeBSD, AlmaLinux, Ubuntu,
Solaris, and IBM AIX. With the goal of integrating networking, storage, authentication, security, and application
services across heterogeneous operating systems

- Engineered core network and identity infrastructure using BIND9 forward/reverse DNS, LDAP centralized
authentication, OpenSSL PKI/TLS certificates, SSH key authentication, VPN connectivity, port forwarding, and ProxyJump routing between systems

- Deployed and managed containerized NGINX services using Docker and Docker Compose, integrating systemd
service management, NFS shared storage, automounting, firewall configuration, and centralized system resources
